## 关卡一：能力圈与商业定性审查

> 不懂不碰，绝不上单。

### V1.1 所有权锚点与三句话自我提问

- 股票是公司所有权的证券化代表，收益来自企业生产力创造的真实财富；买入理由若只是 K 线形态、热点概念、别人都在买 → 不通过。
- **自我提问**：能否用 3 句话向非专业人士讲清——标的靠什么赚钱？客户为什么非买它的产品/服务不可？收入具体由什么构成？
- **能力圈根本之问**：“我凭什么能在这笔交易中赚到钱？”
  - 盲目追风（不通过）：依赖二手新闻、媒体宣导、论坛大V、看图说话，无原始资料支撑；
  - 深刻洞察（通过）：基于公告、年报、招股说明书等一手资料，对产业链议价权、行业生命周期、竞争格局（CR3/CR5）有量化透视，能用大白话讲清盈利机制。

### V1.2 主营业务结构与收入来源穿透（实操核对）

- 查验利润表“营业收入”明细构成，计算主营业务产品/服务收入占总收入比重，**硬性要求主营收入占比 ≥ 80%**；
- 强行剔除变卖资产等“营业外收入”与“补贴收入”，确认核心盈利建立在具备商业可持续性的主营业务之上。

### V1.3 竞争战略路线判定与逻辑匹配

| 战略 | 数据特征 | 校验要求 |
|---|---|---|
| 成本领先战略 | 低毛利率、高总资产周转率、高存货周转率 | 靠薄利多销与规模效应，周转指标必须极高 |
| 差异化战略 | 高且稳定的毛利率 | 靠产品溢价、技术与品牌壁垒，毛利率不得大起大落 |

经营数据与声称的战略路线不匹配（如自称差异化却毛利率持续下滑）→ 不通过。

### V1.4 行业属性与认知边界强制圈定

- 区分技术高频迭代行业（研发支出费用化侵蚀当期利润，资本化则面临巨额减值风险）与商业模式成熟稳定行业；
- 凡超越个人专业认知、无法理解其技术转化路径或行业竞争格局的标的，一律划入能力圈之外。

### V1.5 能力圈三问与原始资料核验

| # | 问题 |
|---|---|
| V1.5a | 我真的看懂它的生意模式吗？ |
| V1.5b | 我能像给 5 岁小孩讲故事一样，讲清它是怎么赚现金流的吗？ |
| V1.5c | 如果股市明天关门、休市五年，我拿着它会慌吗？ |

- 必须审阅公司**近三年年报及交易所公告原文**；仅凭三手研报、论坛推荐决策 → 不通过。
> 看不懂的机会，错过不可惜——那本来就不属于你的机会。

## 关卡二：财报防伪与真实盈利核查

> 有假账或财务粉饰迹象绝对否决。自我提问：近 3–5 年经营活动现金流净额是否持续 ≥ 净利润？利润是否真实变现而非纸面富贵？

### V2.1 现金流与净利润匹配度硬性校验

- 连续 3 年计算 **经营活动现金流量净额 / 净利润**：该比率 **< 1.0**，或出现 **Δ应收账款 > Δ营业收入**，判定为“无现金支撑的虚假繁荣利润”，直接归入否决项；
- 关键背离信号：净利润持续增长而经营现金流持续恶化或为负，通常意味着应收款堆积、存货积压甚至虚构利润。利润可有水分，现金流很难造假。

### V2.2 固定成本吸收效应与营运资金陷阱审计

- 穿透重资产/高固定成本企业（厂房设备折旧占比高）的产销量数据。警惕企业盲目扩大生产（产量远超销量），把固定生产成本分摊至更多产成品、压低单位成本，从而**人为拉高账面毛利率、将未实现利润掩埋于存货**；
- 判定逻辑：**存货显著堆积 + 毛利率逆势上升 + 营业收入无同步增长或销量下滑** → 虚假毛利，直接拦截。

### V2.3 研发支出资本化穿透审查

- 清查研发投入划入费用化（研究阶段，计管理费用/研发费用）与资本化（开发阶段，计无形资产）的金额与比例；
- 会计准则事实：自研技术商业化不确定性极高，通常直接费用化，仅外购技术或满足严格开发条件的少部分支出可资本化；
- 无实质商业化证据却大额资本化以隐瞒当期亏损、虚增资产 → 触发红线。

### V2.4 折旧/摊销与资产减值完整性排查

- 核查固定资产折旧率、无形资产摊销及各项减值损失（应收坏账准备、存货跌价准备、固定资产减值）；
- 严查通过少提折旧、拖延计提坏账或存货减值来虚增资产与净利润。

### V2.5 表外负债与关联资金占用穿透审计

- 穿透“其他应收款”：存在大额资金被控股股东或关联方无偿借用（实质资金占用/挪用）→ 直接否决；
- 查验“其他应付款”、隐藏担保与或有负债；
- 区分**经营性租赁**（表外业务，租金仅计费用）与**融资性租赁**（表内业务，资产计入表内，未来租金计入长期应付款），防止利用经营租赁隐藏真实债务。

## 关卡三：护城河与自由现金流品质

> 无持续竞争优势不下单。自我提问：同业发动价格战时，公司能否靠差异化保住毛利率？赚到的利润能否自由分红，而非被迫全额再投入厂房设备？

### V3.1 五力模型与报表科目映射（产业链议价能力审计）

| 方向 | 强议价能力表现 | 弱势信号 |
|---|---|---|
| 对上游供应商 | **应付账款高、预付账款极低**（无偿占用供应商资金） | 预付账款偏高、应付账款极低（被迫预付抢货） |
| 对下游客户 | **预收账款高、应收账款极低**（先钱后货） | 应收居高不下、存货积压、预收为零（被迫赊销） |

### V3.2 竞争加剧下的毛利率韧性校验

调取行业产能过剩或价格战时期的历史报表：售价下降而固定成本刚性，毛利率大幅衰退者 → 缺乏护城河。

### V3.3 杜邦拆解与 ROE 质量

ROE = 净利率 × 总资产周转率 × 权益乘数，须辨明高 ROE 的驱动力：

| 类型 | 特征 | 标杆/风险 |
|---|---|---|
| 高净利率驱动 | 品牌壁垒强、定价权高、低周转 | 贵州茅台：净利率约 49.5%、ROE 约 37%、周转率约 0.58 |
| 运营效率/多业务驱动 | 供应链卓越、第二曲线扩张 | 美的集团：净利率约 9.6%、海外收入约 42.7%、ToB 收入约 26.8% |
| 高权益乘数驱动 | 靠财务杠杆堆砌 ROE | **高风险**：行业下行极易触发债务危机 |

### V3.4 自由现金流（FCF）品质与资本开支类型

- **自由现金流 = 经营活动现金流量净额 − 维持性资本开支**（现金流量表“购建固定资产、无形资产和其他长期资产支付的现金”）；
- 硬性区分“高资本开支吞金机器型”（如造纸行业每一万吨产能需投入约 1 亿元固定资产，经营现金流被资本开支抹平）与“轻资产高自由现金流型”。

### V3.5 未分配利润与管理层资本分配记录

- 审查留存收益是否转化为 ROE 提升、持续现金分红或股份回购；
- 频繁将未分配利润用于高溢价盲目并购、毁灭股东价值 → 劣质管理层。

## 关卡四：估值折扣与安全边际极限定价

> 无安全边际不上单。自我提问：在极保守情景（增长停滞或小幅下滑）下，当前价格是否仍有足够安全垫？

### V4.1 极限压力测试下的收益能力推演

摒弃任何乐观高增长预估，在**业绩零增长乃至营业收入/净利润下滑 10%–20%** 的极限情景下，重新测算盈利水平与估值底线。买入价是决定长期复利与风险暴露的核心变量。

### V4.2 相对估值法陷阱

- **PE 周期陷阱（最致命）**：煤炭、钢铁、航运、化工、有色等强周期股，顶点 EPS 异常偏高、静态 PE 显得极便宜。例：股价 100 元，顶点 EPS 10 元、PE 仅 10 倍；正常周期 EPS 仅 2 元，真实 PE 为 50 倍。顶点买低 PE 将遭戴维斯双杀，周期股应优先看 **PB、产能周期、库存周期**；
- **PB 匹配**：是否与资产质量及真实 ROE 匹配？应收、存货、商誉是否存在大额减值风险；
- **PEG 误区**：增长率假设是否过度乐观、忽视基数扩大后的增速递减；
- **EV/EBITDA**：跨资本结构比较时是否还原真实企业价值与净债务。

### V4.3 绝对估值（DCF/DDM）与分部估值（SOTP）

- DCF 对自由现金流、折现率（WACC）、永续增长率三参数极度敏感，微小变动可致估值翻倍偏差；永续增长率不得隐含“企业永续超越 GDP 增速”；
- **禁止用假设随意贴现、参数凑数的复杂 DCF 进行自我催眠与价格合理化**；
- 建模回测必须排除：未来函数、数据窥探、过度拟合、生存者偏差；
- SOTP：多业务公司是否重复计算资产、过度给予未盈利第二曲线高估值。

### V4.4 调整后流动比率与短期借款续贷风险

- 中国市场现实：短期借款常态化“借新还旧”滚动续贷，流动比率普遍在 1.0–2.0；
- **调整后流动比率 = 流动资产 /（流动负债 − 短期借款）**，剔除可滚动短期借款后仍须 **> 1.0**；
- 若剔除后 < 1.0，且 EBIT 无法覆盖利息支出 → 判定为短期断贷即破产的极高债务风险。

### V4.5 清算价值与股东权益保障度

- 对比总市值与净资产（股东权益 = 资产 − 负债）；
- 保守清算：应收账款按坏账风险打折、存货按变现折扣打折、固定/无形资产扣除大幅减值后，计算极端清算下的真实股东权益，评估市值安全垫。

### V4.6 EBIT、利息保障与隐含回报率（硬性测算）

- **EBIT = 净利润 + 所得税 + 财务费用中的利息支出**；
- **利息保障倍数（已获利息倍数）= EBIT / 利息支出**；
- **隐含回报率 = EBIT / 总市值**，硬性要求显著高于无风险收益率（10 年期国债收益率）与 WACC。

### V4.7 倒推市场隐含预期与三情景矩阵

- 当前价格隐含了怎样的增长预期？是否需要垄断级市占率（CR3/CR5）或不可能实现的毛利率才能履约？已过度计价（Priced in）极致预期 → 无安全边际；

| 情景 | 假设与参数 | 决策要求 |
|---|---|---|
| 保守 | 增速 3%–5%、WACC 10%–12%、不计第二曲线 | 现价低于保守估值（通常折价 30% 以上）→ 强力建仓区 |
| 中性 | 过去 3–5 年平均效率、合理 TAM、增速取中位数 | 现价基本匹配 → 结合信号分批建仓 |
| 乐观 | 份额快速提升、第二曲线兑现、永续增长取上限 | 现价接近/超越乐观估值 → **绝对禁止买入** |

## V5 极简避坑速查（小A）

- **逆向思维**：此刻决定基于理性分析，还是被贪婪/恐惧推着走（联动 C6/C7）？
- **耐心**：买入后三年不涨甚至跌 20% 拿得住吗？（闲钱检查联动 C1，不通过即红线）
> 市场短期是投票机，长期是称重机。
- **五步走**：① 筛选对象（只在能力圈内找生意简单、现金流好的公司）→ ② 估值算账（未来约 10 年能赚多少现金、现价是否打折）→ ③ 等待（99% 的时间是无聊的，绝不为交易而交易）→ ④ 出击（好机会出现时满世界坏消息，用盆接不用勺子）→ ⑤ 坐得住（基本面没变坏、价格没离谱，就什么都不做）。

## V 模块否决红线汇总

| 编号 | 否决红线（命中即 🔴 禁止交易） |
|---|---|
| V-R1 | 无法用 3 句话讲清核心盈利模式、客户粘性来源及具体收入构成 |
| V-R2 | 主营业务收入占比 < 80%，核心利润依赖营业外收入、补贴或变卖资产 |
| V-R3 | 依赖无法验证的复杂技术概念、概念炒作或远期宏观故事，缺乏实质经营与确定现金流支撑 |
| V-R4 | 未审阅近三年年报与交易所公告原文，仅凭研报摘要、论坛或大V推荐决策 |
| V-R5 | 连续 3 年经营现金流/净利润 < 1.0（或现金流长期严重背离净利润），或 Δ应收账款 > Δ营业收入 |
| V-R6 | 固定成本吸收效应：存货显著堆积 + 毛利率逆势上升 + 营收不增或销量下滑 |
| V-R7 | 无实质商业化证据却大额研发资本化隐瞒亏损、虚增资产；或少提折旧、拖延计提坏账/存货减值 |
| V-R8 | 存在关联方资金占用（其他应收款）、隐藏担保或表外负债、财报重述及历史造假行为 |
| V-R9 | 股权质押超 50%、关联交易不公允、同业竞争利益输送等治理隐患 |
| V-R10 | 身处无差异化价格战行业，毛利率与资产周转率持续衰退 |
| V-R11 | 高资本开支却无法产生自由现金流的吞金机器；频繁高溢价盲目并购毁灭股东价值 |
| V-R12 | 强周期股在盈利顶点仅凭低 PE 买入，未结合 PB、产能与库存周期核验 |
| V-R13 | 现价接近/高于乐观情景估值、处于历史估值百分位高位，安全边际为零或负；或用参数凑数的 DCF 自我催眠 |
| V-R14 | 剔除短期借款后调整后流动比率 < 1.0，且 EBIT 无法覆盖利息支出 |
| V-R15 | EBIT 隐含回报率未显著高于 10 年期国债收益率与 WACC |
