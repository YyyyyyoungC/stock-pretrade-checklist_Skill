# H 模块：短线题材自检（爆发第一天值不值得跟踪）

> 适用：短线题材、热点跟踪、打板（持仓 1–5 日）。本质是**筛选跟踪对象、判断谁有资格成为主线，不是追最热**。必须与 C 模块（仓位、流动性、止损纪律）和 T 模块（买点卖点）同时使用；明示这是资金博弈，止损必须机械执行。

## H1 有没有逻辑

### H1.1 七类上涨逻辑（先归因）

| # | 逻辑类型 | 说明 |
|---|---|---|
| ① | 政策催化 | 新政策出台、监管转向 |
| ② | 行业景气变化 | 行业进入上行周期、需求回暖 |
| ③ | 产品/技术突破 | 新产品发布、关键技术落地 |
| ④ | 重大事件 | 行业大会、突发事件、地缘变化 |
| ⑤ | 价格变化 | 大宗商品/产品涨价、供需错配 |
| ⑥ | 产业趋势 | 长周期产业变革（如 AI、新能源） |
| ⑦ | 市场新叙事 | 市场开始讲的新故事、新主线 |

### H1.2 关键标准与灵魂一问

判断标准**不是新闻够不够大，而是逻辑有没有继续被展开的空间**——能不能持续吸引研究、讨论和资金回流。

```
灵魂一问：这个题材明天、后天，还能继续被市场讨论吗？
  ✅ 能 → 有持续性，值得跟踪
  ❌ 不能 → 一次性刺激，警惕一日游
```

> 大新闻只决定它能不能涨停；“故事还能不能讲下去”才决定值不值得跟踪。

## H2 有没有资金

短线走势最终取决于资金是否愿意持续参与。**不看涨幅，看成交深度。**

资金确认 = 成交深度 + 群体效应 + 赚钱效应扩散，逐项核验：

| # | 检查项 | 看什么 |
|---|---|---|
| H2.1 | 板块成交额 | 有没有真金白银进来（增量资金，而非存量对倒） |
| H2.2 | 涨停数量 | 有没有形成群体效应，而非单兵突进 |
| H2.3 | 内部扩散 | 前排能不能带后排，赚钱效应是否扩散 |

资金是否认可，才是短线关键。只有股价脉冲、没有成交深度 → 不通过。

## H3 有没有梯队

板块内部结构齐备，题材质量才高：

```
先锋龙头   ── 打开高度，建立辨识度
核心容量票 ── 承接大资金，提升参与层级
后排补涨   ── 验证扩散，形成板块效应
```

**龙头 + 容量 + 梯队 + 扩散，四者齐备 = 高质量题材。** 龙头往往是整个题材/板块最敏感的情绪温度计之一。

## H4 一日游陷阱与真假鉴别

### H4.1 警惕一日游

早盘快速拉升、多只涨停、刷屏讨论，第二天往往高开低走、集体掉队。

> 不是只看“今天有没有人抢”，而要看“抢完以后，明天还有没有继续抢的理由”。**区分爆发与主线的关键是持续性，不是当天冲得多猛。**

### H4.2 判断题材真假的三个关键

1. 有没有**资金回流**？分歧后资金是否重新回来；
2. 龙头有没有**承接**？炸板后是否有人接；
3. 后排有没有**扩散**？资金是否继续挖掘补涨。

### H4.3 对比案例（同样十几只涨停，质量天差地别）

- ❌ 12 只涨停、全是小一字板、缺容量核心、换手不足 → 虚胖，走不远；
- ✅ 6 只涨停、龙头换手上板 + 容量 + 梯队 + 扩散齐备 + 资金回流 → 结构扎实。

### H4.4 一日游题材的 5 个常见信号

出现以下特征，降低持续性预期（命中越多越接近一日游）：

1. 只有消息，没有**持续逻辑**；
2. 只有一两只股票强；
3. **成交量**跟不上；
4. 冲高之后**不断回落**；
5. 没有**真正有辨识度的核心**。

> 这 5 个信号不是为了否定机会，而是避免把情绪脉冲当成主线。

## H5 爆发当日六步流程

题材爆发第一天，按顺序走，**不要先下结论**：

1. 查催化：为什么涨？（对照 H1.1 七类逻辑）
2. 看成交：有没有增量资金？（H2.1）
3. 找核心：谁有辨识度？（龙头）
4. 看梯队：结构完整吗？（H3）
5. 看下午：有没有回流和扩散？（H4.2）
6. 综合评判：是否纳入跟踪/是否按 T 模块买点介入。

铁律：题材质量判断的本质是筛选跟踪对象、判断谁有资格成为主线，**不是追最热**。介入仍须回到 T 模块确认买点、C 模块冻结仓位与止损。

## H 模块否决红线汇总

| 编号 | 否决红线（命中即 🔴 禁止交易/禁止追入） |
|---|---|
| H-R1 | 答不出上涨逻辑归属（七类全不沾），或灵魂一问“明后天还会不会被讨论”答案为否，属一次性消息刺激 |
| H-R2 | 无成交深度、无增量资金：板块成交额跟不上、涨停无群体效应、内部不扩散 |
| H-R3 | 无辨识度龙头、无容量核心、无后排梯队，仅一两只股票脉冲或全是无量一字板 |
| H-R4 | 已出现冲高不断回落、炸板无人承接、分歧后资金不回流等一日游信号仍追入 |
| H-R5 | 题材已处于全场刷屏、全员皆知的加速末期，以“怕错过”为由追高（联动 T-R1、C7 FOMO 熔断） |
