## T1 买点四要素

### T1.1 趋势——先判断大方向

用 K 线结构看高低点：

- 高点越来越高 + 低点不断抬高 → 上升结构；
- 反之 → 下降结构。
- ⚠️ **跌得多 ≠ 趋势结束**（最常见错觉，禁止以“便宜了”作为抄底理由）。

### T1.2 位置——分清四个阶段

| 阶段 | 特征 | 风险收益 |
|---|---|---|
| ① 启动区 | 成本低，但分歧大 | 待确认 |
| ② 趋势中段 | 确认增强、结构好 | ✅ 最佳博弈区 |
| ③ 加速阶段 | 共识抬升、波动放大 | 风险渐增 |
| ④ 高位扩张 | 最拥挤 | ❌ 风险最大 |

> 好买点 = 逻辑已得到一定确认，但风险收益结构尚未明显恶化的位置。

### T1.3 盈亏比——至少大于 1:3（硬卡口）

```
盈亏比 =（入场点 → 目标位的空间）÷（入场点 → 失效点/止损位的空间）
```

看 K 线先问三件事：

1. 价格从哪里入场？
2. 错了哪里失效（止损位）？
3. 对了空间够不够（目标位）？

> 好买点不只是“它可能涨”，而是**错了亏多少、对了赚多少**。盈亏比 < 1:3 一律不通过；下单前用计算器现算并与 C2 单笔风险（≤1%）联动核验。

### T1.4 确认信号——不猜支撑，等市场验证

- ✅ 止跌：下跌动能减弱；
- ✅ 站回关键位：重新回到结构上方；
- ✅ 放量突破：上方套牢盘被消化、筹码充分换手；
- ✅ 低点抬高：买方提前介入。

> 不是因为跌下来就买，而是等它跌下来以后，**证明自己跌不动**。

## T2 三类标准买点

| 买点 | 介入条件（须同时满足） |
|---|---|
| **平台突破** | 长期箱体震荡后首次有效突破：①收在关键位上方；②有成交量配合；③次日不跌回原区间；④不要离突破位太远 |
| **突破后第一次回踩** | 压力位转为支撑位；回踩**缩量、能站稳、重新转强**后再介入。⚠️ 不是跌回来就买，而是能否站住 |
| **趋势二次启动** | 上涨→整理→再上涨；整理不破坏结构、整理期成交量逐步萎缩；再次有效突破时介入。⚠️ 趋势中继不是“高位还能追”，而是完成了新的整理与确认 |

## T3 四个不能买的位置

1. ❌ **连续加速后追入**——上涨空间已被消耗（对应阶段④）；
2. ❌ **下降趋势里抄底**——跌幅大不等于趋势结束；
3. ❌ **没有失效点/止损点的买入**——下跌后只能靠情绪扛；
4. ❌ **距离支撑位太远**——正常回踩也会造成大幅浮亏。

## T4 买入前七问

> 下单前依次自问，**有一个答不上来，就先不交易。条件满足才交易，不满足就继续等待。**

| # | 问题 | 判定 |
|---|---|---|
| T4.1 | 现在是什么趋势？有没有明确上升趋势？ | 无上升结构 → 不通过 |
| T4.2 | 我买的是什么结构？突破/回踩/中继？距离支撑位多远？ | 说不清结构或远离支撑 → 不通过 |
| T4.3 | 确认信号能否验证我的逻辑？（对照 T1.4 四类信号） | 无确认信号、靠猜测 → 不通过 |
| T4.4 | 哪里能证明我错了？（失效点/止损位） | 答不出失效点 → 红线 T-R2 |
| T4.5 | 我准备承担多少风险？（联动 C2：仓位×止损幅度 ≤ 1%） | 算不出绝对亏损额 → 不通过 |
| T4.6 | 潜在空间与风险是否匹配？（盈亏比 ≥ 1:3） | 不达标 → 不通过 |
| T4.7 | 如果今天没大涨，我还会想买吗？ | 答案为“不会”说明是 FOMO 驱动 → 转 C6/C7 处理 |

## T5 卖出规则

| 卖点 | 触发条件 |
|---|---|
| **短期结构被破坏** | 跌破最近一个重要低点 |
| **关键支撑失效** | 买入逻辑对应的结构位失效（与入场卡片的失效点一致） |
| **加速后的衰竭** | 巨量、剧烈震荡、冲高回落 |

卖出执行与 C5 三重止损/三类出场联动：触发即机械化执行，禁止盘中拉大止损距离。

**记忆口诀**：看趋势 → 选位置 → 算盈亏比 → 等确认信号 → 过七问清单 → 再下单。

## T 模块否决红线汇总

| 编号 | 否决红线（命中即 🔴 禁止交易） |
|---|---|
| T-R1 | 处于下降结构却以“跌得多/便宜了”为由抄底，或在阶段④高位扩张区连续加速后追入 |
| T-R2 | 没有明确失效点/止损位的买入；或距支撑位过远、正常回踩即造成超出风险预算的浮亏 |
| T-R3 | 盈亏比 < 1:3，或无法同时说清入场点、止损位、目标位 |
| T-R4 | 无任何确认信号（无止跌、未站回关键位、无放量突破、无低点抬高），纯靠预测买入 |
| T-R5 | 买入动机是“今天不买就涨了/怕踏空”，T4.7 答案暴露 FOMO，且心理熔断未解除 |
