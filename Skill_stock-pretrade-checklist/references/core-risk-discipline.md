# C 模块：通用风控纪律（每次自检必读）

> 本模块对所有风格生效。生存是第一要务：投资的本质是管理风险而非追求暴富，控制回撤的战略价值远高于短期暴利。以下规则在建仓前以数学逻辑冻结，不接受盘中讨价还价。
>
> 资料来源：用户《投资前自我反问与决策自检清单》六维框架（风险、心理、纪律、落签部分）。

## C1 资金性质前置检查

| # | 检查项 | 合格标准 |
|---|---|---|
| C1.1 | 是否为闲钱 | 未来 3–5 年不用的钱；买入后三年不涨甚至跌 20% 不影响生活 |
| C1.2 | 资金来源 | 自有资金；不得是借贷资金、杠杆资金、应急准备金、短期有确定用途的钱 |
| C1.3 | 持有承受力 | 价值长线必须答得出“买入后三年不涨、甚至跌 20%，我拿得住”；答不出即不合格 |

## C2 风险预算硬约束

| 维度 | 基础规则 | 极端触发动作 |
|---|---|---|
| 单笔亏损预算 C2.1 | **单笔风险 = 仓位比例 × 止损幅度% ≤ 总资金 1.0%**（保守取 0.5%–1.0%） | 达止损线无条件限价单清仓；**绝对禁止盘中拉大止损距离** |
| 单股仓位上限 C2.2 | 单只标的建仓金额建议 **15%–20%**，绝对上限 **20%**，禁止孤注一掷重仓 | 因上涨被动超标 → 分批止盈降回 20% 线下 |
| 总仓位 C2.3 | 小资金实盘初期，或大趋势处于水下（MACD 双线在 0 轴下方）→ 总仓 **20%–30%** 试错 | 趋势水下强制封顶 30% 以下或空仓；主升浪才按策略阶梯加仓 |
| 月度最大回撤 C2.4 | 组合月度回撤达预设阈值（**5%–10%**） | 强制降仓至极低水平、停止新开仓，联动心理日志复盘后再恢复 |
| 加仓纪律 C2.5 | 严禁无计划“越跌越买”摊平亏损；加仓须安全边际进一步扩大**且**基本面经新财报数据验证 | 条件不满足的加仓按冲动交易处理（见 C-R9） |

核算要求：每笔交易必须在下单前算出**绝对最大亏损金额**（元）= 总资金 × 单笔风险比例。算不出这笔数字，禁止下单。

## C3 回撤数学与卡玛比率

- 卡玛比率 Calmar = 年化收益率 / 最大回撤。例：年化 20%、回撤 10%（Calmar 2.0）远优于年化 30%、回撤 40%（Calmar 0.75）。
- 回撤回本数学（自检时用计算器现算）：回撤 40% 需再涨 **66.7%** 才回本；回撤 50% 需再涨 **100%** 翻倍才回本。控制回撤是复利不断裂的基石。

## C4 A股交易成本与制度卡点

**全套交易成本（测算频繁交易摩擦时必须逐项计入）：**

| 费目 | 费率 | 收取方式 |
|---|---|---|
| 印花税 | 0.5‰ | 单边，仅卖出收取 |
| 过户费 | 0.01‰ | 双向，沪深全市场 |
| 交易规费 | 0.0541‰ | 双向 |
| 券商佣金 | 最高 3‰，单笔不足 5 元按 5 元收取 | 双向 |

**制度性卡点（自检必问）：**

- C4.1 **T+1 交收**：当日买入次日才能卖出，短线计划必须考虑无法当日纠错。
- C4.2 **跌停板流动性枯竭**：是否预案了标的连续跌停、无对手盘、完全卖不掉的极端情形？小盘股、高质押股、问题股尤其要问。
- C4.3 **沪市指定交易**：跨券商迁移或实盘过渡时，一个账户只能指定一个沪市交易参与人，撤指定/变更指定是常见卡点，须提前确认。

## C5 三重止损与三类出场

### 黑天鹅三重止损（机械化执行，触发即办）

1. **逻辑止损**：买入逻辑被基本面数据证伪 → 无条件清仓。
2. **价格止损**：触及预设止损位或亏损比例上限 → 强制出场。
3. **时间止损**：预定时间窗口内持续横盘、预期动量未兑现 → 主动降仓。

### 三类卖出（分类明确，触发即执行，严禁拖延）

- **逻辑卖出（基本面证伪）**：投资假设被公告、财报或行业变化证伪，或护城河被破坏、出现财务粉饰/造假迹象、资产负债率急剧升高、利息保障倍数（EBIT/利息，见 V4.6）剧降 → 无条件清仓，不受亏损比例与成本价影响。
- **估值卖出（泡沫化）**：股价大幅超越内在价值、触及乐观情景估值上限、PE/PB 达历史极高分位，或隐含回报率（EBIT/总市值）低于无风险收益率 → 分批止盈、分档减仓。
- **风险与趋势卖出（技术/风控硬约束）**：触发价格止损位，或中长期均线死叉破位 → 强制离场；趋势单可用“上调保护位（移动止损）”代替一次性清仓以锁住利润。

## C6 认知偏差排查与强制反向论证

逐项让用户回答诊断提问；承认有偏差倾向记 ⚠️，明显处于偏差驱动状态记 ❌（转 C7 熔断）。

1. **过度自信**：是否把近期大盘顺风或几次偶然盈利误判为自己的能力？是否因连赢而盲目加仓、破坏风控？
2. **确认偏误**：是在客观审视全部信息（含财报预警、研报风险提示），还是只搜集支持看涨的理由、对反向证据视而不见？
3. **损失厌恶**：是否执着于买入成本价？拒绝止损是因为基本面未坏，还是无法承受兑现亏损的痛苦、心存“不卖就不算亏”的幻觉？
4. **FOMO 踏空恐慌**：下单是因为出现了系统入场信号，还是看到股价飞涨、板块飙升、怕错过而冲动追高？
5. **近期偏差**：是否默认过去几天的强势/涨停会无限延续，忽略均值回归与周期见顶信号？
6. **羊群效应**：决策建立在独立的原始资料复核上，还是被社交媒体、论坛大V、炒作热点裹挟？
7. **强制反向论证（空头观点测试 · 关卡五核心动作）**：必须在自检报告中列出**至少 3 个最强看空逻辑**（如行业产能过剩、应收账款坏账、下游议价能力削弱、替代技术出现），并逐一基于财报事实与商业逻辑有力驳斥；**无法列出或驳不倒者，不得下单。**

## C7 情绪体温计与强制熔断

下单前最后一分钟必测。**触及任意一项，立即执行对应动作，本轮买入终止，无例外。**

| 维度 | 状态识别 | 强制执行动作 |
|---|---|---|
| 报复性交易 | 刚止损亏损，急于下一笔“翻本” | **封锁账户 24 小时**，禁止任何买入指令 |
| 连亏焦虑 | 连续亏损中，极度焦虑、丧失理性判断 | **实盘暂停，退回模拟盘**，直至心态恢复 |
| 连胜亢奋 | 连续盈利后膨胀，产生“看透市场”幻觉 | **单笔仓位强制减半、封顶 10% 以内** |
| 精力耗竭 | 睡眠不足、情绪低落、身体疲惫、注意力分散 | **当日绝对禁手**，离开交易终端 |

## C8 策略落地七步与逻辑失效条件

### 策略标准化落地七步（任何买入信号必须通过）

1. 定义股票池（能力圈 + 第一手资料初筛）；
2. 定义信号变量（明确量化的买入触发因子）；
3. 设置过滤条件（排除财务违规、高质押、估值泡沫标的）；
4. 写入场与失效条件（明确基本面证伪指标）；
5. 历史样本内验证（逻辑在历史周期中的表现）；
6. 样本外验证（排除过度拟合与数据窥探，确保跨周期稳定）；
7. 生成单笔交易卡片（完全冻结交易参数）。

策略验证中必须排除：未来函数（Look-ahead Bias）、数据窥探（Data Snooping）、过度拟合（Overfitting）、生存者偏差（Survivorship Bias）。

### 四类策略的买入验证口径

- 价值低估：低估值 + 强现金流 + 资产质量优良（年报复核 + 估值区间确认）；
- 成长趋势：营收利润持续扩张 + 研发投入支撑 + 行业高景气；
- 动量强势：相对强度领先 + 量价配合 + 强势板块共振；
- 事件驱动：业绩预告、高分红、回购、重组等特定时间线触发。

### 逻辑失效条件（Premise Invalidation，下单前必须书面写出 ≥2 条）

回答：“哪些具体事件或财务数据的改变，会彻底推翻我的买入逻辑？”参考示例：

- 核心产品毛利率同比下滑超过 5 个百分点；
- 经营活动现金流量净额连续两个季度大幅恶化；
- 研发进度证伪或核心产品未通过审批；
- 行业驱动要素（政策、技术、流动性）发生根本性逆转。

## C9 盘中三禁令与盘后三层复盘

**入场前**：必须已填好含入场理由、失效条件、计划持有期、最大可亏损额的交易卡片。

**盘中三大禁令：**

1. 严禁盘中临时拉大止损距离；
2. 严禁因盘中冲动追高而临时加仓；
3. 严禁凭感觉修改既定止盈目标。

**盘后三层强制复盘：**

1. 市场层：资金与情绪；
2. 策略层：信号与执行；
3. 个股层：基本面追踪。

亏损单必须做两次以上深度反思。复盘只对照事前冻结的计划，不得事后篡改计划为错误开脱。

## C10 决策一页纸 12 问与落签

价值长线风格在下单前逐项回答 12 问（短线/趋势风格使用交易卡片，但同样适用“答不出即不交易”原则）：

1. 这是一家什么公司？（一句话说清核心业务、行业地位、主要产品）
2. 公司靠什么赚钱？（商业模式、主营收入构成、利润增长核心要素）
3. 未来增长来自哪里？（行业 TAM 扩张 / 市占率提升 / 新产品 / 海外拓展）
4. 核心竞争优势是什么？（品牌 / 专利技术 / 成本领先 / 网络效应）
5. 当前估值合理吗？（估值方法，现价相对保守与中性估值的安全边际）
6. 为什么现在买？（具体系统信号：极度低估 / 放量突破 / 事件兑现）
7. 买入逻辑失效条件是什么？（≥2 条可量化的恶化指标，触发即清仓）
8. 最坏情况下亏多少？（按止损位与仓位精确计算最大绝对亏损金额）
9. 计划投入多少仓位？（核验单股 ≤ 20% 红线）
10. 预期持有多久？（短期波段 / 中线趋势 / 长线价值）
11. 达到什么条件卖出？（逻辑卖出、估值止盈分档、价格/均线止损）
12. 哪些信息会改变当前观点？（需持续追踪的关键指标：月度销售、原材料价格、政策、高管变动等）

**落签规则**：12 问中任何一项给不出清晰、客观、有数据支持的回答，或命中任一红线 → 绝对禁止交易。可签署文本模板见 `../assets/decision-onepager-template.md`。

## C11 C 模块否决红线汇总

| 编号 | 否决红线（命中即 🔴 禁止交易） |
|---|---|
| C-R1 | 资金非闲钱：3–5 年内有确定用途，或属借贷/杠杆/应急资金 |
| C-R2 | 算不出本笔最大绝对亏损额，或单笔风险 > 总资金 1%，或根本没有止损位 |
| C-R3 | 计划单股仓位 > 20%，或趋势水下/实盘初期总仓位超出 20%–30% 试错区间且无系统依据 |
| C-R4 | 情绪体温计四项任一触发且熔断未解除 |
| C-R5 | 交易卡片（或 12 问一页纸）任一必填项无法客观填写 |
| C-R6 | 无事前冻结的书面计划，属盘中临时起意、追高加仓或为交易而交易 |
| C-R7 | 明确表示“跌了就死扛/不卖就不算亏”，拒绝接受止损纪律 |
| C-R8 | 无法列出至少 3 个反向看空逻辑，或无法基于财报与商业事实有力驳斥（强制反向论证未通过） |
| C-R9 | 计划无计划“越跌越买”摊平亏损，加仓未经新财报验证、安全边际未扩大 |
